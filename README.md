# IELTS Mock Test

اختبار آيلتس أكاديمي محاكي كامل (Listening – Reading – Writing – Speaking) يعمل في المتصفح بدون أي سيرفر أو مكتبات.

## الملفات
```
index.html   الصفحة الرئيسية
style.css    التصميم
data.js      محتوى الاختبار (النصوص، الأسئلة، الإجابات)
app.js       منطق الاختبار والتقييم
```

## رفعه على GitHub Pages
1. ادخل github.com وسوّ مستودع جديد (New repository)، مثلاً اسمه `ielts-mock`، واختر **Public**.
2. اضغط **Add file → Upload files** واسحب الملفات كلها مع المجلدين `css` و `js` (لازم يبقى الترتيب نفسه).
3. اضغط **Commit changes**.
4. روح **Settings → Pages**، وتحت **Source** اختر `Deploy from a branch`، والفرع `main` والمجلد `/ (root)`، ثم **Save**.
5. بعد دقيقة أو دقيقتين يصير الموقع على:
   `https://اسم-حسابك.github.io/ielts-mock/`

## ملاحظات
- **المتصفح:** استخدم Chrome أو Edge. Edge أصواته أطبع للـ Listening، والاثنين يدعمون تحويل كلامك لنص في الـ Speaking.
- **الـ Speaking** يحتاج إذن المايك، وGitHub Pages يشتغل على https فما فيه مشكلة.
- **النتائج** تنحفظ في متصفحك بس (localStorage)، فلو غيّرت الجهاز أو مسحت بيانات المتصفح تروح.
- **التقييم:** الاستماع والقراءة يتصححون تلقائياً بجدول التحويل الرسمي. الكتابة والمحادثة تعطيك مؤشرات مقاسة + برومبت تنسخه لـ Claude عشان يقيّمك كممتحن، وبعدها تدخل الدرجات وهو يحسب الباند.
- **إضافة اختبار ثاني:** كل المحتوى موجود في `js/data.js`، وتقدر تعدّله أو تضيف عليه بنفس الهيكلة.
